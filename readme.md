# Инструменты для Google PageSpeed

Модуль правит HTML страницы перед отдачей, чтобы меньше ругался Lighthouse: подсказки по загрузке CSS/JS, lazy у картинок, отложенные стили. По желанию можно вырезать Метрику, GA и GTM — обычно только для робота проверки.

Настройки: **Настройки → Инструменты для Google PageSpeed → Настройки**. После установки всё выключено, пока сам не включишь и не нажмёшь «Применить».

Три вкладки. **Опции** — готовые переключатели. **Тэг link** — URL’ы, для которых добавить preload/prefetch и похожее. **Тэг script** — каким скриптам повесить async или defer. У опции можно выбрать «для всех» или «только для робота Google PageSpeed».

Если вырезаешь аналитику только для робота — живым людям счётчик остаётся, роботу нет. Это осознанный компромисс, не включай «на всякий случай». Отложенный CSS иногда даёт мигание стилей — проверь на копии сайта. Lazy не ставится на первую картинку в HTML (часто это LCP). Сниппеты Метрики/GTM, если вставлены нестандартно, regex может не поймать.

Это не замена нормальной оптимизации шаблона, а костыль поверх уже собранной страницы.
