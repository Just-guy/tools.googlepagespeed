# Инструменты для Google PageSpeed

Модуль для 1С-Битрикс, который модифицирует HTML-страницы перед отдачей клиенту, чтобы снизить количество замечаний Lighthouse к производительности: расставляет подсказки по загрузке CSS/JS, добавляет `lazy` для изображений, откладывает загрузку стилей. Опционально позволяет вырезать счётчики Яндекс.Метрики, Google Analytics и Google Tag Manager — как правило, только для робота проверки.

## Возможности

- Подсказки по загрузке CSS/JS (`preload`, `prefetch` и аналогичные директивы)
- `lazy`-загрузка изображений
- Отложенная загрузка стилей
- Вырезание Яндекс.Метрики, Google Analytics и GTM (опционально, в т.ч. только для робота)
- **Отложенная загрузка пресетов** (idle / первое взаимодействие): Яндекс.Метрика, Google Analytics — чекбоксы на вкладке «Опции»

## Установка

1. Скопируйте модуль в `/local/modules/` (или `/bitrix/modules/`).
2. Установите его через **Настройки → Настройки продукта → Модули**.
3. Перейдите в **Настройки → Инструменты для Google PageSpeed → Настройки**.

После установки все опции выключены. Модуль начнёт работать только после того, как вы включите нужные пункты и нажмёте **«Применить»**.

## Настройки

Интерфейс состоит из трёх вкладок:

| Вкладка | Назначение |
| --- | --- |
| **Опции** | Готовые переключатели базовых оптимизаций |
| **Тэг `link`** | URL'ы, для которых нужно добавить `preload` / `prefetch` и аналогичные директивы |
| **Тэг `script`** | Скрипты, которым следует назначить `async` или `defer` |

Для каждой опции можно выбрать область действия: **«для всех»** или **«только для робота Google PageSpeed»**.

## Важные замечания

> **Вырезание аналитики только для робота** — живым посетителям счётчик продолжает работать, роботу — нет. Это осознанный компромисс, а не поведение «по умолчанию». Не включайте его «на всякий случай».

- **Отложенный CSS** иногда вызывает мигание стилей при загрузке. Проверяйте результат на копии сайта, прежде чем применять на продакшене.
- **`lazy`-загрузка** не устанавливается на первое изображение в HTML — как правило, это LCP-элемент.
- **Сниппеты Метрики и GTM**, вставленные нестандартным способом (например, через комплексный компонент или сторонний плагин), могут не попасть под регулярное выражение и не будут вырезаны / отложены.
- **Отложить Метрику / GA** не вырезает счётчики насовсем: скрипты уезжают из первого кадра и подключаются после idle или жеста. Для Метрики и GA вставляется stub (`ym` / `gtag`), чтобы ранние цели не падали. Не включайте одновременно «Вырезать…» и «Отложить…» для одного и того же на одних и тех же посетителях — вырезание сработает раньше и откладывать будет нечего.

## Область применения

Модуль — это не замена нормальной оптимизации шаблона, а временное решение поверх уже собранной страницы. Используйте его как дополнение, а не как основной инструмент производительности.
